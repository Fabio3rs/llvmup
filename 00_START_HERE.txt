   Fix Time: < 2 minutos (substituir return → continue)

🔴 BUG #2: Tilde range incorreto em Bash (ALTA)
   Arquivo: llvm-functions.sh:1604-1619
   Problema: ~1.2.3 ativa versões que não deveria (1.2.0, 1.2.1, 1.2.2)
   Fix Time: < 5 minutos (extrair patch, preservar em cálculo)
   
   IMPACTO: Ativa versões semanticamente incorretas

🟡 ISSUE #3: API inconsistente em PowerShell (MÉDIA)
   Arquivo: Llvm-Functions-Core.psm1:577-586
