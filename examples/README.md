# LLVMUP examples

- `.llvmup-config.example`: project settings to adapt to your project.
- `example-version-usage.sh`: examples using installed-version helpers.
- `install-examples.sh`: installation customization examples.

Run shell examples from the repository root and review them first: examples may
use existing toolchains or change project files. For isolated automated checks,
use `llvmup doctor --deep` or the Bats/Pester suites in `tests/`.

See the [command reference](../README.md), [installation guide](../docs/INSTALL.md)
and [build examples](../docs/BUILD_EXAMPLE.md).
